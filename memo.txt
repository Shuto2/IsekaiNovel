# IsekaiNovel プロンプト向け仕様書 ver.1.5

## 1. サービス概要（本質）
- 目的
  - ユーザーがAIと共同で物語を創作する体験を提供
  - 単なる読み物ではなく、プレイヤーの発言・行動・心の声で物語が進化するインタラクティブ小説

- 価値
  - プレイヤーが物語世界に入り込み、キャラクターや状況に影響を与えられる
  - AIによる描写・キャラクター反応で手間なく連続したストーリーを生成
  - 世界観やキャラクターを自由に設定でき、オリジナル作品作成が可能

- 実装前提
  - ローカル限定で動作（公開不可）
  - HTML + JavaScript + CSS で構築
  - Gemini API（gemini-2.5-flash）を直接API呼び出しで利用
  - 保存はローカルストレージ
  - ネットワーク接続はGemini API呼び出しのみ

- プログラムとしての構造
  - フロントエンド / UI
    - トップページ：プロジェクト一覧表示・新規作成
    - 個別プロジェクト画面：エピソード一覧・キャラクター管理
    - エピソード編集画面：チャット型UIでターン管理、下部入力バー
  - バックエンド / AI処理
    - Gemini APIを直接呼び出し、プレイヤー入力に基づきターン単位で物語生成
    - メモリー管理（直近ターン、ストーリー全体、長期記憶）
    - JSON形式でターン履歴を保持、保存・再開可能
  - データ保存
    - ローカルストレージ（デフォルト）
    - クラウド保存はオプトイン・暗号化

## 2. 物語構造
- Story（物語）
  - 複数のEpisodeを内包
  - タイトル、あらすじ、世界設定、登場人物、エピソード配列、プレイヤープロファイル、状態、履歴ログを保持

- Episode（エピソード / 章）
  - 複数ターンで構成
  - 章タイトル（編集可能）、AI生成あらすじ、ターン配列、状態変化を保持

- Turn（ターン / 1往復）
  - プレイヤー入力（speech, thought, action）
  - AI出力（narration, character_reactions）
  - 使用メモリーIDリスト、タイムスタンプを保持

## 3. トップページ（プロジェクト一覧）
- 上部バーなし
- メイン画面はカード表示
  - プロジェクトカード例：タイトル / 最終更新 / 最新エピソード
  - 各カードに「開く」「削除」ボタン
- 下部ナビゲーションなし
- 新規プロジェクト作成ボタンを画面下に固定
- 必要に応じて右上に検索／フィルタ小アイコン

## 4. 個別プロジェクト画面
- 上部バー（固定）
  - 左端10%：トップページに戻るボタン
  - 中央90%：物語タイトル表示（編集可能）

- メイン領域（エピソード一覧）
  - エピソードカードに「タイトル / 最終更新 / 状態 / 開くボタン」
  - カードをドラッグして順番変更可能
  - 下部に「新規エピソード作成」ボタン

- エピソード操作はカード上で完結、上部バーにボタンは不要

## 5. 個別エピソード編集画面
- 上部バー（固定）
  - 左端10%：プロジェクト画面に戻る
  - 中央90%：エピソードタイトル（編集可能）

- メインチャットビュー
  - チャット形式でターン単位表示
  - ターンブロック例：
    - Player (発言): 「こんにちは！」
    - Player (心の声): （緊張するな…）
    - Player (行動): ドアを開ける
    - AI (描写): 部屋の中は静まり返っていた…
    - Character A: 「やっと来たのね」
  - プレイヤーとAI出力は色分け、吹き出しで明示
  - スクロール自動で最新ターン追従
  - ノベルビュー切替可能

- 下部入力バー
  - 左端10%：丸ボタン（入力モード切替：発言／心の声／行動）
  - 入力欄90%：自由テキスト、右端に送信ボタン（矢印）

- メモリー可視化（オプション）
  - 右スライドパネルで直近ターンや重要メモリー確認
  - タグ・キャラクター・エピソード別フィルタ

- ターン進行フロー
  1. プレイヤー入力
  2. Gemini API呼び出しでAI生成（描写・キャラクター反応）
  3. チャットビューに表示
  4. メモリー更新
  5. 次ターン待機

## 6. データ構造
- Story: id, title, world, characters, episodes, memories
- Episode: id, title, turns, summary
- Turn: id, player_input (speech, thought, action), ai_output (narration, character_reactions), used_memories, timestamp
- メモリー
  - 種類：セッション、ストーリー、長期、エフェメラル
  - 参照優先度：直近ターン > ストーリーメモリー > 長期 > 関連イベント

## 7. AI入出力仕様
- 入力
  - プレイヤー入力JSON
  - 直近ターンメモリー
  - ストーリーメモリー要約
- 出力
  - AI生成JSON（narration, character_reactions）
  - 使用メモリーIDリスト
- 文体
  - なろう系ライトノベル
  - 発言「」、心の声（）、行動は独立段落
- 出力順序
  1. 描写（narration）
  2. キャラクター反応
  3. プレイヤー補助解釈（必要時）

## 8. 保存・再開
- ローカルストレージ保存（自動・手動）
- 完結後は読書専用モード
- クラウド保存はオプトイン・暗号化


## 9. 拡張計画
- 感情値・関係性モデル
- 自動あらすじ生成
- 作品共有・公開
- AIキャラ共著モード
- 埋め込みベース記憶リコール

## 10. 最近のUI/UX改善ログ

- **UIアイコンの統一**:
  - アプリケーション全体のアイコンをGoogle Fonts (Material Symbols)に統一し、デザインの一貫性を向上。
  - 対象: 戻る、送信、設定、編集、入力モード切替ボタン。

- **タイトル編集機能の改善**:
  - プロジェクト名とエピソード名の編集方法を、直接編集から編集アイコン (`edit_square`) をクリックしてプロンプトで入力する方式に変更。
  - エピソード名は「第X話：エピソード名」の形式で表示されるようにし、話数の識別を容易にした。

- **プロジェクト設定機能の追加**:
  - プロジェクト詳細画面ヘッダーに設定 (`settings`) ボタンを設置。
  - クリックするとモーダルが開き、「世界観」「登場人物」を入力・保存できる機能を追加。
  - 保存された設定はAIへのプロンプトに組み込まれ、物語生成に反映される。

- **チャット入力UIの改善**:
  - 入力モード（行動、発言、心の声）の選択を、プルダウンメニューからアイコントグルボタンに変更し、直感的な操作性を実現。
  - メッセージ入力バーを画面下部に固定 (`position: sticky`) し、チャット履歴が長くなっても常に表示されるように改善。

- **情報表示の強化と安定化**:
  - プロジェクト一覧カードに「エピソード数」と「最終更新日時」を表示し、プロジェクトの状況を一覧で把握しやすくした。
  - 「戻る」ボタンが正常に機能しない問題を修正し、ページ遷移時に前の画面が正しく再描画されるようになった。

- **エピソード内キャラクター管理機能の追加**:
  - エピソード編集画面のヘッダーに、登場キャラクターを管理する機能を追加。
  - プロジェクト全体・エピソード固有のキャラクターを一覧表示し、チェックボックスでそのエピソードに登場させるかを選択できる。
  - キャラクター追加ボタン (`person_add`) からモーダルを開き、エピソード固有のキャラクターを登録できる。
  - 登録されたキャラクターはリストに追加されるが、登場させるにはユーザーが明示的にチェックボックスをオンにする必要がある。
  - AIへのプロンプトには、チェックボックスがオンになっているキャラクターの情報のみが渡される。

- **プレイヤーによる物語操作機能の追加**:
  - プレイヤーが【System】モードでAIに直接的な指示（例：キャラクターの生死、イベントの発生）を送れる機能を追加。
  - AIはプレイヤーからの【System】指示を絶対的な命令として解釈し、物語に反映させる。
  - チャット入力UIを改善し、クリックで展開するアイコン選択方式に変更。新しい【System】モード（`settings_suggest`アイコン）もここに含まれる。

- **プロジェクト設定画面のキャラクター一覧表示**:
  - プロジェクト設定画面に、プロジェクトで使用されている全キャラクターを一覧表示する機能を追加。

- **AIからのシステムメッセージ表示**:
  - AIが物語の進行に必要な情報を尋ねる【System】メッセージを、チャット画面に専用のスタイルで表示する機能を追加。
